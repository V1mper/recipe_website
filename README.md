# ПП-рацион

**Веб-приложение на Flask** для подбора блюд правильного питания с учётом **КБЖУ** (калории, белки, жиры, углеводы): каталог по приёмам пищи, карточки рецептов, конструктор дня с пересчётом суммы в браузере и автоподбор рациона под заданные суточные цели.

> Контекст курсовой темы: *«Разработка гибридного веб-приложения для подбора ПП-рационов с контролем КБЖУ»*.
> В этом репозитории реализована **веб-часть**

---

## Возможности

| Раздел | Описание |
|--------|----------|
| **Главная** | Обзор разделов и краткое описание проекта |
| **Категории** | Завтрак, обед, ужин, перекус — списки ПП-блюд |
| **Рецепт** | Ингредиенты, шаги приготовления, **КБЖУ на порцию** |
| **Случайное блюдо** | Случайный выбор из базы для идей меню |
| **Конструктор дня** (`/ration`) | Ручной выбор блюд с **живой суммой КБЖУ** (JS) и **автоподбор** четырёх приёмов под целевые ккал и БЖУ (Python) |
| **Предложить рецепт** | Отправка текста на «модерацию» (запись в SQLite) |

---

## Стек

- **Python 3** + [Flask](https://flask.palletsprojects.com/) 3.x
- **SQLite** (`recipes.db`) — категории, рецепты, ингредиенты, связи, заявки пользователей
- **Bootstrap 5** + собственные стили (`static/css/style.css`)
- **Jinja2** шаблоны в `templates/`

## Быстрый старт

### 1. Клонирование и переход в каталог

```bash
cd recipe_website
```

### 2. Виртуальное окружение

```bash
python -m venv venv
```

**Активация**

- **Git Bash / MSYS:** `source venv/Scripts/activate`
- **cmd:** `venv\Scripts\activate.bat`
- **PowerShell:** `venv\Scripts\Activate.ps1`

### 3. Зависимости

Рекомендуется вызывать pip через интерпретатор окружения (так надёжнее, чем «голый» `pip` на Windows):

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

> Если раньше папку `venv` **копировали** из другого проекта, внутри может остаться путь к чужому `python.exe`. В этом случае удалите `venv` и создайте заново командой `python -m venv venv`.

### 4. Запуск

```bash
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000/**

Остановка сервера: `Ctrl+C` в терминале.

## Переменные окружения (необязательно)

| Переменная | Назначение |
|------------|------------|
| `FLASK_SECRET_KEY` | Секрет для сессий и flash-сообщений (в продакшене задайте свой случайный ключ) |

Пример (PowerShell):

```powershell
$env:FLASK_SECRET_KEY = "ваш-случайный-длинный-ключ"
python app.py
```

## База данных

- Файл **`recipes.db`** создаётся автоматически при первом запуске, если его нет.
- Если обнаружена **устаревшая схема** (например, без полей КБЖУ у рецептов), файл пересоздаётся с демо-данными — см. `ensure_db()` в `models.py`.

## Основные маршруты

| URL | Назначение |
|-----|------------|
| `/` | Главная |
| `/categories` | Категории приёмов пищи |
| `/category/<название>` | Список блюд в категории |
| `/recipe/<название блюда>` | Страница рецепта |

| `/ration` | Конструктор дня и автоподбор |
| `/share` | Форма «предложить рецепт» |
